# 줄기 기억

Julgi는 한 작업을 "줄기"로 묶는다. 줄기에는 세션이 여러 개 이어질 수 있고, 세션이 바뀌어도 남는 것이 줄기 기억이다. 이 세션이 끝난 뒤 같은 줄기를 이어받는 세션은 대화를 못 보고 기억만 본다.

## 읽기

```sh
~/.julgi/bin/julgi memory          # 내 줄기의 기억
~/.julgi/bin/julgi memory "환불"   # 이름·레포·요약에 "환불"이 있는 줄기의 기억
```

기억은 지난 세션이 남긴 글이라 지금과 다를 수 있다. 코드나 파일로 확인할 수 있는 것은 확인하고 쓴다.

## 적기

```sh
~/.julgi/bin/julgi note "결정: 환불은 쿠폰별로 따로 반올림한다. 합쳐서 하면 1원이 남는다."
```

적을 것:
- 내린 결정과 그 이유
- 겪은 함정 (왜 안 됐는지, 어떻게 피했는지)
- 방향이 바뀐 것, 사용자가 정해 준 것
- 다음에 할 일

적지 않을 것: 코드를 보면 아는 것, 진행 중계("파일을 읽었다"), 이미 적힌 것. 한 번에 한 가지를 한두 문장으로 적는다.

적으면 Julgi가 1~2초 안에 줄기 기억 파일에 덧붙인다. 답은 돌아오지 않으니 확인하려고 기다리지 않는다.
