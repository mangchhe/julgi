# 다른 줄기에 일 넘기기

Julgi 안에는 세션이 여럿 돈다. 이 세션이 다른 레포의 일이나 다른 작업까지 떠안으면 컨텍스트만 커진다. 그런 일은 맞는 줄기로 넘긴다.

## 순서

1. 넘길 곳을 찾는다.
   ```sh
   ~/.julgi/bin/julgi threads "앱"       # 이름·레포·요약에서 찾기
   ```
2. 넘긴다. 받는 세션은 이 대화를 못 본다. 그 글만 보고 일할 수 있게 쓴다.
   ```sh
   ~/.julgi/bin/julgi send "앱 주문 화면" "server 레포의 /orders 응답에 refundable 필드가 추가됐다(브랜치 feature/refund-flag). 앱 쪽 파서가 이 필드를 받도록 고쳐 달라. 없으면 false로 본다."
   ```
3. 맞는 줄기가 없으면 새 줄기로 넘긴다. 어느 레포에서 열지는 Julgi가 글을 보고 고른다. 레포 이름을 글에 넣으면 그 레포에서 열린다.
   ```sh
   ~/.julgi/bin/julgi send new "notifier 레포: 알림 템플릿에 주문 취소 문구를 추가한다. ..."
   ```

## 넘기는 글에 넣을 것

- 무엇을 해 달라는지 (한 문장)
- 왜 필요한지와 이쪽에서 바뀐 것 (브랜치, 파일, 인터페이스)
- 끝났다고 볼 기준

## 알아 둘 것

- 넘기고 나면 답을 기다리지 않는다. 답은 그 세션에 쌓이고 사용자가 거기서 본다.
- 보낸 것은 되돌릴 수 없다. 대상이 맞는지 `julgi threads`로 먼저 본다.
- 사용자가 시키지 않았는데 일을 여러 줄기로 쪼개 뿌리지 않는다. 범위를 벗어난 일이 나왔을 때만 쓴다.
- Julgi의 "한 일"(⌘Y)에 "세션이 넘김"으로 남는다.
