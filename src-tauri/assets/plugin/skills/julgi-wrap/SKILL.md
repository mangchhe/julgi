# 세션 정리

## 일이 끝났을 때

1. 다음에 누가 봐도 알 수 있게 결과를 기억에 남긴다.
   ```sh
   ~/.julgi/bin/julgi note "끝: 환불 반올림 수정 머지됨(PR #1852). 남은 것 없음."
   ```
2. 줄기를 끝난 것으로 한다. 목록에서 내려가고 검색으로는 계속 찾는다.
   ```sh
   ~/.julgi/bin/julgi done
   ```

끝내기 전에 확인한다: 커밋하지 않은 변경, 올리지 않은 브랜치, 사용자에게 답하지 않은 질문이 남아 있으면 끝내지 말고 먼저 알린다.

## 세션이 너무 길어졌을 때

```sh
~/.julgi/bin/julgi handoff
```

이 답이 끝나면 Julgi가 인계 글을 부탁하고, 그 글만 들고 같은 줄기의 새 세션을 연다. 인계 글을 미리 쓸 필요는 없다. 부탁이 오면 그때 쓴다.

일이 한창인 중간에는 하지 않는다. 하던 단계를 마친 뒤에 한다.

## Julgi가 만든 스킬을 썼다면

이 세션에서 `~/.julgi/grown/skills/` 아래의 스킬을 따라 했는데 순서가 틀렸거나, 빠진 단계가 있었거나, 사용자가 바로잡은 곳이 있었으면 마무리하기 전에 그 `SKILL.md`를 고친다. 다음에 같은 데서 막히지 않게 하려는 것이다. 고친 뒤 맨 아래 "고친 기록"에 날짜와 무엇을 왜 고쳤는지 한 줄을 붙인다(없으면 그 제목을 만든다). 잘 통했으면 건드리지 않는다.
