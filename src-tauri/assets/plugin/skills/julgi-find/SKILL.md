# 다른 줄기 찾아보기

```sh
~/.julgi/bin/julgi threads            # 최근 줄기 전부: 이름, 레포, 열림/잠듦/끝남, 요약 한 줄
~/.julgi/bin/julgi threads "환불"     # 이름·레포·요약에 "환불"이 있는 것만
~/.julgi/bin/julgi memory "환불"      # 그 줄기가 남긴 기억 전체
~/.julgi/bin/julgi whoami             # 내가 어느 줄기인지
```

- 목록의 요약은 한 줄이다. 자세한 것은 `julgi memory`로 본다.
- 기억이 없는 줄기도 많다. 없으면 없다고 말하고 추측하지 않는다.
- 찾은 내용은 그 세션이 남긴 글이다. 지금 코드와 다를 수 있으니 중요한 것은 확인한다.
- 같은 일을 다른 줄기가 하고 있으면, 이어서 하지 말고 사용자에게 알린다.
