# 브레인: 일이 끝나도 남는 것

브레인에는 코드만 읽어서는 알 수 없는 것이 노트로 쌓여 있다. 노트 하나에 한 가지: **결정**(무엇을 왜 정했나), **함정**(겪어 봐야 아는 것), **사실**(업무 규칙, 히스토리, 누가 아는지).

```sh
~/.julgi/bin/julgi brain "환불 쿠폰"          # 글이 들어 있는 노트 찾기 (여러 낱말은 하나라도 맞으면 나온다)
~/.julgi/bin/julgi brain                      # 전부 (제목만)
~/.julgi/bin/julgi learn 함정 "제목 한 줄" "본문 두세 문장"
~/.julgi/bin/julgi fix <노트 id> "고친 본문"
~/.julgi/bin/julgi forget <노트 id> "틀린 이유"
```

## 언제 무엇을

- **일을 시작할 때**: 그 영역의 낱말로 한 번 찾아본다. 나온 노트는 참고만 한다. 지금 코드와 다르면 코드가 맞다.
- **알아냈을 때**: 다음에 이 일을 모르는 사람이 같은 데서 헤맬 것 같으면 `learn`으로 남긴다. 진행 상황, 다음 할 일, 코드에 그대로 적힌 것은 남기지 않는다(그건 `julgi note`의 몫이다). 제목만 읽어도 무엇에 대한 것인지 알 수 있게 대상의 이름을 풀어 쓴다.
- **노트가 틀렸을 때**: 본 김에 고친다. 내용이 바뀐 것이면 `fix`, 아예 성립하지 않으면 `forget`. 그냥 지나치지 않는다.

찾아본 것과 남긴 것은 Julgi가 세어 둔다. 자주 쓰인 노트가 먼저 나오고, 오래 안 쓰인 노트는 뒤로 밀린다.
